# El coste de gestionar mal un proyecto IT. (Spanish)

El fundador de una start-up viene a pedirme ayuda.



Desafortunadamente, el equipo anterior que desarrolló el producto ya no está localizable. :/



El producto es totalmente funcional, pero hay algunas cosas que arreglar / mejorar. Cosas menores dice el fundador. :\)



Miro el código base con la ayuda de un desarrollador de confianza. Una pesadilla.



¿Qué le digo?



Fácil, le dije al fundador que arreglar bugs / finalizar características inacabadas incluye:



- Entender el código base 1 semana



- añadir funciones / corregir errores 1-2 semanas



- Refactorizar el código según sea necesario para evitar errores de regresión. 1 -2 semanas



Sí, es entre 2 y 3 veces lo que él espera como costes.



¿Qué ha hecho?



Contrató a un desarrollador de Upwork \(de la India\) para arreglar / mejorar la función lo antes posible. Problemas de dinero, dice. Para seguir adelante, le respondo.



Pero este es el coste de gestionar mal un proyecto informático.  ¿Todavía hay tiempo para hacer las cosas bien? Sí.



¿Qué debería haber hecho?



La opción más rentable es contratar a un CTO/técnico independiente que gestione el tiempo parcial para poder mantener los conocimientos técnicos y la calidad del código, y mantenerlo como socio estratégico.
